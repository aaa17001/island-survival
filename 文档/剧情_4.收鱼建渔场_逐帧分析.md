## 游戏机制分析

### 1. 渔场生产系统
- **前置条件**：拥有水塘 + 渔场建筑
- **生产流程**：鱼群出现 → 角色捕鱼 → 自动结算 → 资源获得
- **产出资源**：金币（主要）、可能还有其他资源（石头/食物等）
- **生产效率**：每轮约产生 +400 和 +700 两种收益

### 2. 鱼群AI行为
- 从水塘边缘开始聚集
- 主动向渔场码头移动
- 捕鱼过程中保持游动循环
- 产量结算后重新聚集（可持续生产）

### 3. 资源收益系统
```
单次渔场产出：
├── +400 × 2 = +800（金币）
├── +700 × 2 = +1400（其他资源）
└── 总计约 +2200 资源
```

### 4. 自动化生产循环
- 渔场一旦建立，即可**自动持续生产**
- 不需要玩家反复操作
- 属于"放置类"经济系统

## 章节总结

**第4章「收鱼建渔场」** 是一个**生产系统教学章节**，通过以下步骤展示：
1. 承接第3章抽水后的水塘场景
