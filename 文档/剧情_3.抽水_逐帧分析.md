## 游戏机制分析

### 1. 抽水Mechanic（核心创新点）
- **操作**：选择抽水泵工具 → 确认 → 观察水位下降动画
- **效果**：大湖 → 草地 + 小水塘
- **收益**：
  - 获得可建设地块（草地）
  - 鹅群自动转移到新水塘（后续产生收益）
  - 金币增加（34K→40K，+6K）
  - 可能获得其他资源（石头等）

### 2. 动物AI行为
- 鹅群对水位变化有**实时反应**
- 从深水区向浅水区/岸边移动
- 当新水塘形成后，自动聚集到新水域
- 群体行为呈现自然的队列聚集效果

### 3. 地形改造系统
- 抽水是一个**地形改造**操作
- 永久改变地块状态（水→草地）
- 为后续建设提供空间
- 属于"环境互动"类核心玩法

### 4. 资源循环设计
```
抽水 → 获得草地 + 金币
草地 → 可建造新建筑
鹅群 → 新水塘 → 渔场收益
```

## 章节总结

**第3章「抽水」** 是一个**核心机制教学章节**，通过以下步骤展示：
1. 引导玩家使用抽水泵工具
2. 展示水位下降的完整动画
3. 演示鹅群的智能反应（跟随水位移动）
4. 展示地形改造的收益（新地块 + 资源）
5. 为后续渔场建设铺垫（新水塘）

**关键设计点**：
- 抽水不仅是为了清除水域，更是为了**创造新的生产空间**
- 动物AI增加了游戏的生动性和反馈感
- 资源收益即时可见，强化玩家成就感
- 字幕叙事简洁，将操作与收益自然衔接
