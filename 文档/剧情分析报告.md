## 四、核心游戏系统总结

### 1. 资源系统
```
五大核心资源：
├── 金币 (Gold) - 通用货币
├── 木材 (Wood) - 建筑基础材料
├── 石材 (Stone) - 高级建筑材料
├── 能量 (Energy) - 生产/升级消耗
└── 宝石 (Gems) - 高级货币/加速道具
```

### 2. 建设系统
- **围墙系统**：防御核心，可扩展多层
- **供水系统**：连接建筑与资源点
- **生产建筑**：渔场、牧场、农田等
- **升级系统**：建筑可升级提升效率

### 3. 战斗系统
- **塔防机制**：利用围墙控制敌人移动
- **围杀战术**：将敌人引入包围圈消灭
- **防御塔**：自动攻击 nearby 敌人

### 4. 经济循环
```
水 → 渔场/牧场/农田 → 产出资源 → 金币 → 扩建/升级
抽水 → 直接产生金币
防御成功 → 保护资产 → 持续生产
```

## 六、技术实现建议

### 推荐引擎
- Unity 2D/3D 混合（推荐）
- Cocos Creator（适合小游戏平台）
- Godot（轻量级开源方案）

### 核心模块架构
```
GameSystem/
├── ResourceSystem/      # 资源管理
├── BuildingSystem/      # 建筑放置/升级
├── WaterSystem/         # 水管连接逻辑
├── DefenseSystem/       # 围墙/塔防
├── EnemySystem/         # 敌人AI/路径
├── CombatSystem/        # 战斗计算
└── EconomySystem/       # 经济循环
```

### 关键算法
1. **水管连通检测**：BFS/DFS检查水源到建筑的连通性
2. **围墙路径控制**：A*寻路 + 围墙碰撞体
3. **资源收益计算**：基于建筑等级和连通的公式
4. **敌人围杀逻辑**：路径引导 + 区域判定
