## 一、章节概述

本章节为游戏的**首个剧情引导关卡**，讲述主角在水上木筏生存过程中，发现并解锁"麦田"新区域的完整流程。核心叙事线：

1. **水上漂泊** → 发现陆地资源点
2. **遭遇敌人** → 红名怪"野人"袭击
3. **建立安全区** → 搭建防御据点
4. **解锁麦田** → 剧情推进，开启新玩法区域

## 三、核心系统提炼

### 3.1 移动系统
- **木筏水上移动**：主角初始载具，可在水面自由移动
- **登陆机制**：木筏可停靠浅滩，玩家可步行探索陆地
- **视角**：固定等距俯视角（isometric），镜头可缩放

### 3.2 战斗系统
- **近战攻击**：武器挥舞动画，红色攻击箭头指示
- **敌人标记**：红名怪以红色文字+血条显示
- **击退机制**：攻击可将敌人击退一定距离
- **清怪逻辑**：消灭所有敌人后战斗结束

### 3.3 建造系统
- **围墙建造**：分段放置，可弯曲环绕形成封闭空间
- **建材运输**：木筏装载建材，靠岸后手动搬运
- **安全区概念**：围墙闭合后形成"安全区"，抵御敌人入侵

### 3.4 剧情引导系统
- **字幕旁白**：底部字幕区显示主角内心独白/剧情对话
- **目标提示**：明确告知玩家下一步行动（"建立安全区"→"解锁麦田"）
- **场景切换**：通过镜头拉远/拉近实现叙事节奏控制
