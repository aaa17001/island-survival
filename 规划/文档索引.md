## 🚀 快速开始

### 1. 打开项目
```
Unity Hub → Open → F:/FGame/源码/Unity
```

### 2. 自动搭建场景
```
IslandSurvival → 自动搭建第1章场景
```

### 3. 运行测试
```
IslandSurvival → 运行单元测试
IslandSurvival → 性能基准测试
```

### 4. 开始游戏
```
点击 Play 按钮
使用 WASD 移动，B 建造，空格推进
```
