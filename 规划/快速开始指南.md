# 快速开始指南

## 环境准备

### 必需软件
- Unity Hub (最新版)
- Unity 2022.3 LTS
- Git (用于 DeerFlow)

### 可选软件
- Visual Studio 2022 (代码编辑)
- Photoshop (美术处理)

## 步骤1: 打开 Unity 项目

```bash
# 方法1: 使用 Unity Hub
1. 打开 Unity Hub
2. 点击 "Open"
3. 选择目录: F:/FGame/源码/Unity
4. 等待项目加载

# 方法2: 直接打开
1. 双击 F:/FGame/源码/Unity/.unityproject (如果存在)
2. 或手动创建新项目后导入脚本
```

## 步骤2: 自动搭建场景

在 Unity Editor 中：
```
菜单栏 → IslandSurvival → 自动搭建第1章场景
```

这将自动创建：
- 11个管理器对象
- 4个场景对象（水面、岛屿、玩家、麦田）
- UI Canvas

## 步骤3: 创建预制体

```
菜单栏 → IslandSurvival → 创建预制体模板
```

将创建：
- Assets/Prefabs/Wall.prefab
- Assets/Prefabs/Enemy.prefab
- Assets/Prefabs/WheatField.prefab

## 步骤4: 运行测试

1. 点击 Play 按钮
2. 测试控制：
   - WASD 移动玩家
   - 鼠标左键攻击
   - B 键建造围墙
   - 空格键进入下一章

## 步骤5: 生成测试报告

```
菜单栏 → IslandSurvival → 生成测试报告
```

报告保存在: `F:/FGame/规划/测试报告_初始搭建.md`

## 常见问题

### Q: Unity 提示脚本错误
**A**: 确保所有脚本都在正确的文件夹中：
```
Assets/Scripts/Core/
Assets/Scripts/Resource/
Assets/Scripts/Building/
Assets/Scripts/Water/
Assets/Scripts/Enemy/
Assets/Scripts/Combat/
Assets/Scripts/Scenes/
Assets/Scripts/UI/
Assets/Scripts/Input/
Assets/Scripts/Editor/
```

### Q: 编译错误 "找不到命名空间"
**A**: 检查命名空间是否正确：
```csharp
namespace IslandSurvival.Core { ... }
namespace IslandSurvival.Resource { ... }
// 等等
```

### Q: 场景对象为空引用
**A**: 确保脚本组件已正确挂载到GameObject上
