## 🎮 快速启动

### 1. 启动Unity
```bash
# Windows
双击 F:/FGame/start_unity.bat

# 或手动
Unity Hub → Open → F:/FGame/源码/Unity
```

### 2. 自动搭建场景
```
菜单栏 → IslandSurvival → 自动搭建第1章场景
```

### 3. 测试游戏
```
点击 Play 按钮
测试: WASD移动 | 鼠标攻击 | B建造 | 空格下一章
```
