# Island Survival - 项目开发总结

## 项目概述
**Island Survival (海岛生存)** 是一款策略经营 + 塔防 + 生存类微信小游戏。
玩家在水上孤岛建立基地，通过资源管理、建筑建设和防御塔防，抵御敌人入侵，逐步扩张生存范围。

## 核心系统设计

### 资源循环
```
水 → 渔场/牧场/麦田 → 产出资源 → 金币 → 扩建/升级
抽水 → 直接产生金币
防御成功 → 保护资产 → 持续生产
```

### 建筑系统
- **围墙**: 防御核心，可升级
- **水塔**: 供水核心，产生金币
- **渔场**: 产出食物
- **牧场**: 产出肉类
- **麦田**: 产出食物（第9章解锁）

### 战斗系统
- 玩家近战攻击
- 围墙阻挡敌人
- 防御塔自动攻击
- 围杀战术
