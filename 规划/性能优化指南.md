# Island Survival - 性能优化指南

## 当前性能目标
- **目标帧率**: 60 FPS
- **内存限制**: < 256MB (微信小游戏)
- **首包大小**: < 4MB

## 优化措施

### 1. 代码优化
```csharp
// ✅ 使用对象池
private Queue<GameObject> _enemyPool = new Queue<GameObject>();

public GameObject GetEnemy()
{
    if (_enemyPool.Count > 0)
    {
        var enemy = _enemyPool.Dequeue();
        enemy.SetActive(true);
        return enemy;
    }
    return Instantiate(enemyPrefab);
}

public void ReturnEnemy(GameObject enemy)
{
    enemy.SetActive(false);
    _enemyPool.Enqueue(enemy);
}

// ✅ 避免频繁的 GetComponent
private Renderer _renderer;
private void Start()
{
    _renderer = GetComponent<Renderer>();
}

// ✅ 使用 Mathf.Clamp 替代条件判断
value = Mathf.Clamp(value, min, max);
```

### 2. 资源优化
```csharp
// 压缩纹理
Texture2D tex = new Texture2D(64, 64);
tex.compression = TextureCompression.Compressed;
tex.wrapMode = TextureClampMode.Clamp;
```

### 3. 物理优化
```csharp
// 减少物理计算
Rigidbody rb = GetComponent<Rigidbody>();
rb.sleepVelocity = 1f;  // 降低休眠阈值
rb.freezeRotation = true;  // 冻结旋转（如果不需要）
```

### 4. UI优化
```csharp
// 静态UI标记
[UIElement]
public Text goldText;

// 只在需要时更新
private void UpdateUI()
{
    if (Mathf.Abs(gold - lastGold) > 0)
    {
        goldText.text = gold.ToString();
        lastGold = gold;
    }
}
```

## 性能监控

### Unity Profiler 关键指标
- **CPU Usage**: < 16ms/frame (60fps)
- **GPU Usage**: < 8ms/frame
- **Memory**: < 200MB
- **GC Allocations**: 避免每帧分配

### 监控代码
```csharp
void Update()
{
    // FPS监控
    fpsCounter++;
    fpsTimer += Time.deltaTime;
    if (fpsTimer >= 1f)
    {
        currentFPS = fpsCounter / fpsTimer;
        fpsCounter = 0;
        fpsTimer = 0f;
    }
    
    // 内存监控
    long memoryMB = GC.GetTotalMemory(false) / (1024 * 1024);
}
```

### 2. 资源懒加载
```csharp
// 延迟加载非关键资源
IEnumerator LoadAsync(string path)
{
    var request = Resources.LoadAsync<GameObject>(path);
    yield return request;
    Instantiate(request.asset);
}
```
