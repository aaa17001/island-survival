# 资源系统设计

## 五大核心资源

| 资源 | 图标 | 初始值 | 用途 | 生产方式 |
|------|------|--------|------|----------|
| 金币 | 💰 | 10K | 通用货币 | 抽水、交易 |
| 木材 | 🪵 | 25K | 建筑基础 | 伐木 |
| 石材 | 🪨 | 20K | 高级建筑 | 采矿 |
| 能量 | ⚡ | 40K | 生产消耗 | 水塔供水 |
| 食物 | 🍖 | 20K | 生存恢复 | 麦田/渔场 |
| 宝石 | 💎 | 5/10 | 加速道具 | 成就 |

## 资源获取公式

### 生产型
```
产量 = 基础产量 × 建筑等级 × 连通系数
```

### 消耗型
```
消耗 = 基础消耗 × 升级系数^等级
```

## 经济循环

```
水 → 渔场/牧场/麦田 → 产出资源 → 金币 → 扩建/升级
抽水 → 直接产生金币
防御成功 → 保护资产 → 持续生产
```

## 数值设计原则

1. **前期**: 资源丰富，快速建立基地
2. **中期**: 资源紧张，需要优化生产链
3. **后期**: 自动化生产，专注防御和扩张
