# 核心玩法设计

## 游戏类型
策略经营 + 塔防 + 生存

## 核心循环
```
探索水域 → 战斗清怪 → 收集资源 → 建造基地 → 解锁新区域 → 抵御入侵
     ↑                                              ↓
     └──────────── 麦田生产食物 ← 围墙保护 ←────────┘
```

## 核心玩法元素

### 1. 基地建设
- 围墙防御系统
- 水管网络（供水）
- 生产建筑（渔场/牧场/麦田）

### 2. 资源管理
- 金币、木材、石材、能量、食物、宝石
- 资源生产/消耗平衡

### 3. 战斗防御
- 围墙阻挡敌人
- 防御塔自动攻击
- 玩家角色近战战斗

### 4. 剧情推进
- 13章线性剧情
- 每章解锁新机制
- 字幕引导新手

## 目标用户
- 休闲策略玩家
- 微信小游戏用户
- 喜欢建设和防御的玩家

## 平台
- 微信小游戏（首选）
- 移动端（iOS/Android）
