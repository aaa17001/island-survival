# 第3章设计：抽水

## 章节目标
引入资源采集机制 - 抽水系统

## 剧情流程

### 场景描述
- 基地周围有大片水域
- 字幕："我把水抽干吧"

### 步骤分解
1. **引导抽水** - 高亮抽水泵选项
2. **选择工具** - 玩家选择抽水泵
3. **开始抽水** - 水位开始下降
4. **观察变化** - 露出新的草地
5. **鹅群反应** - 动物逃离水域
6. **建造渔场** - 在新区域建造渔场
7. **章节完成** - 获得渔场产出

## 新增机制

### 抽水系统
- 水位逐渐下降动画
- 露出新的可建造区域
- 鹅群逃离动画

### 资源产出
```
抽水收益:
  直接产生金币: 100/次
  新土地: 可用于建造渔场
  渔场产出: 食物/秒
```

### 建筑解锁
- 渔场需要在水边建造
- 渔场产出食物
- 渔场可升级

## 技术实现

### 水位管理
```csharp
// 水位插值动画
float progress = timer / duration;
currentLevel = Mathf.Lerp(startLevel, endLevel, progress);
```

### 鹅群AI
```csharp
// 逃离行为
Vector3 escapeDirection = Random.insideUnitCircle * speed;
transform.position += escapeDirection * Time.deltaTime;
```

### 区域解锁
```csharp
// 水位低于阈值时解锁
if (waterLevel < threshold)
{
    UnlockBuildingArea(position);
}
```

## 测试要点
- [ ] 水位正确下降
- [ ] 新区域正确解锁
- [ ] 鹅群动画正常
- [ ] 资源正确产出
- [ ] 渔场可建造

## 数值设计

| 参数 | 初始值 | 说明 |
|------|--------|------|
| 水位下降时间 | 10秒 | 从满到干 |
| 鹅群数量 | 5只 | 逃离动画 |
| 渔场建造成本 | 1000金+500木 | 首次建造 |
| 渔场产出 | 5食物/秒 | 基础产出 |
