# 第3章设计：抽水

## 章节目标
引入资源采集机制 - 抽水

## 剧情流程

### 场景描述
- 基地周围有大片水域
- 字幕："我把水抽干吧"

### 步骤分解
1. **引导抽水** - 高亮抽水泵选项
2. **选择工具** - 玩家选择抽水泵
3. **开始抽水** - 水位开始下降
4. **观察变化** - 露出新的草地
5. **章节完成** - 获得新区域

## 新增机制

### 抽水系统
- 水位逐渐下降
- 露出新的可建造区域
- 鹅群逃离（动画效果）

### 资源产出
```
抽水收益:
  直接产生金币: 100/次
  新土地: 可用于建造
```

## 测试要点
- [ ] 水位正确下降
- [ ] 新区域正确解锁
- [ ] 鹅群动画正常
- [ ] 资源正确产出
