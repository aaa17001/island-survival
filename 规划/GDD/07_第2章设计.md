# 第2章设计：围墙

## 章节目标
让玩家学习围墙建造系统

## 剧情流程

### 场景描述
- 玩家建立安全区后，发现需要更多防御
- 字幕："我需要扩建围墙"

### 步骤分解
1. **引导建造** - 高亮空地，提示建造围墙
2. **建造围墙** - 玩家放置第一段围墙
3. **围墙闭合** - 玩家完成环形围墙
4. **防御测试** - 敌人来袭，验证围墙效果
5. **章节完成** - 安全区成型

## 新增机制

### 围墙系统
- 分段建造（每次放置一段）
- 可弯曲环绕
- 有耐久度（被攻击会损坏）
- 可升级增强防御

### 资源消耗
```
围墙建造:
  Lv1: 50木 + 20石
  Lv2: 100木 + 50石
  Lv3: 200木 + 100石
```

## 测试要点
- [ ] 围墙可分段建造
- [ ] 围墙可弯曲
- [ ] 资源正确扣除
- [ ] 围墙有耐久度显示
- [ ] 敌人攻击围墙时有反馈
