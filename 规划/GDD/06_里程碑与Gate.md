# 项目里程碑与 Gate 验证

## 里程碑规划

```
M0: 项目基线 (第1周)
    ├── 完成项目结构搭建
    ├── 确认技术选型
    └── GDD 文档完成
    ↓
🎯 GATE-0: 项目准备验证
    ├── [ ] 项目目录结构完整
    ├── [ ] 核心类已创建
    └── [ ] GDD 文档 reviewed
    ↓
M1: 核心玩法原型 (第2-3周)
    ├── 玩家移动系统
    ├── 基础战斗系统
    ├── 围墙建造系统
    └── 第1章可玩原型
    ↓
🎯 GATE-1: 核心玩法验证 (必须通过)
    ├── [ ] 玩家可移动
    ├── [ ] 可建造围墙
    ├── [ ] 可攻击敌人
    └── [ ] 第1章剧情可播放
    ↓
M2: 生产系统 (第4-5周)
    ├── 水管系统
    ├── 渔场/牧场/麦田
    └── 资源循环
    ↓
🎯 GATE-2: 生产系统验证
    └── [ ] 资源可持续生产
    ↓
M3: 完整版本 (第6-8周)
    ├── 所有13章剧情
    ├── 敌人波次系统
    └── 性能优化
```

## 验收标准

### GATE-0: 项目准备
- [x] 项目目录结构已创建
- [x] 核心类已编写
- [ ] GDD 文档完整

### GATE-1: 核心玩法
- [ ] 玩家可在地图移动
- [ ] 玩家可建造围墙
- [ ] 玩家可攻击敌人
- [ ] 敌人可被击败
- [ ] 资源可收集
- [ ] 第1章剧情可完整播放

### GATE-2: 生产系统
- [ ] 水管连接逻辑正确
- [ ] 建筑可产出资源
- [ ] 资源消耗正确

## 风险登记

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| Unity 性能问题 | 高 | 中 | 低分辨率、对象池 |
| 玩法单调 | 中 | 中 | 多样化敌人、事件 |
| 工期延误 | 高 | 中 | 分阶段交付、MVP优先 |
