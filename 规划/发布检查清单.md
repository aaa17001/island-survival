## 发布流程

### 微信小游戏发布
1. **构建 WebGL**
   ```
   Unity → IslandSurvival → 构建 WebGL
   ```

2. **导出项目**
   - 打开构建目录
   - 复制 Build/webgl.loader.js
   - 复制 TemplateData/ 目录

3. **导入微信开发者工具**
   - 新建小游戏项目
   - 导入导出文件
   - 替换 game.json

4. **预览测试**
   - 真机预览
   - 性能分析
   - 功能测试

5. **上传发布**
   - 点击上传
   - 填写版本信息
   - 提交审核

## 注意事项

### 文件大小限制
- 首包: < 4MB
- 总包: < 20MB
- 分包: 按需加载

### 性能要求
- 帧率: 稳定 60fps
- 内存: < 256MB
- 启动时间: < 3秒

### 微信小游戏规范
- 不使用外部网络请求
- 不访问设备敏感权限
- 符合内容审核要求
