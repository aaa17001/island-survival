## 🚀 启动方式

### 方式1: Unity Hub（推荐）
```
1. 打开 Unity Hub
2. 点击 'Open' 按钮
3. 选择路径: F:/FGame/源码/Unity
4. 等待项目加载完成
5. 菜单栏 → IslandSurvival → 自动搭建第1章场景
6. 点击 Play 按钮测试游戏
```

### 方式2: 双击启动
```
双击 F:/FGame/start_game.bat
选择 '1. 启动 Unity Editor'
```
