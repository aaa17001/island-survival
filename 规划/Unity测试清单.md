# Unity Editor 测试清单

## 打开项目后执行

### 1. 检查编译状态
- [ ] Console 窗口无红色错误
- [ ] 所有脚本编译成功

### 2. 自动搭建场景
```
菜单栏 → IslandSurvival → 自动搭建第1章场景
```
- [ ] 检查 Scene 视图是否有对象
- [ ] 检查 Hierarchy 是否有管理器

### 3. 运行游戏
- [ ] 点击 Play 按钮
- [ ] 等待场景加载

### 4. 功能测试
- [ ] WASD 移动正常
- [ ] 鼠标左键攻击有效
- [ ] B 键建造围墙
- [ ] U 键升级围墙
- [ ] 空格推进章节
- [ ] 字幕正确显示
- [ ] 资源UI正确显示

### 5. 调试控制台
```
菜单栏 → IslandSurvival → 生成测试报告
```
- [ ] 检查 Debug Console 输出
- [ ] 记录任何错误或警告

### 6. 单元测试
```
菜单栏 → IslandSurvival → 运行单元测试
```
- [ ] 检查测试通过数量
- [ ] 修复失败的测试
