# 构建与发布指南

## 构建目标

| 平台 | 菜单命令 | 输出路径 |
|------|----------|----------|
| WebGL (微信小游戏) | IslandSurvival → 构建 WebGL | F:/FGame/Builds/ |
| PC Standalone | IslandSurvival → 构建 PC Standalone | F:/FGame/Builds/ |
| Android | IslandSurvival → 构建 Android | F:/FGame/Builds/ |
| iOS | IslandSurvival → 构建 iOS | F:/FGame/Builds/ |

## 快速构建

### 1. 配置微信小游戏
```
菜单栏 → IslandSurvival → 配置微信小游戏参数
```

### 2. 运行项目检查
```
菜单栏 → IslandSurvival → 运行项目检查
```

### 3. 构建 WebGL
```
菜单栏 → IslandSurvival → 构建 WebGL (微信小游戏)
```

### 4. 清理缓存
```
菜单栏 → IslandSurvival → 清理构建缓存
```

## 微信小游戏发布流程

### 步骤1: 构建
1. 运行 `配置微信小游戏参数`
2. 运行 `构建 WebGL`
3. 等待构建完成

### 步骤2: 导出
构建完成后，打开 `F:/FGame/Builds/` 目录，找到:
```
WeChatMiniGame_WebGL_yyyyMMdd_HHmmss/
├── Build/
│   └── WebGL.loader.js
├── TemplateData/
└── index.html
```

### 步骤3: 导入微信开发者工具
1. 打开微信开发者工具
2. 选择 "小游戏" 项目
3. 导入构建输出目录
4. 预览测试

### 步骤4: 上传发布
1. 点击 "上传" 按钮
2. 填写版本信息
3. 提交审核

## 性能优化建议

### WebGL 优化
- [x] 启用代码剥离 (`stripEngineCode`)
- [x] 使用 Release 配置
- [ ] 压缩纹理
- [ ] 合并网格
- [ ] 对象池

### 文件大小控制
- 目标：< 4MB (微信小游戏限制)
- 当前预估：~8MB
- 优化措施：
  1. 移除未使用的材质
  2. 压缩图片资源
  3. 使用 LOD 系统

## 已知限制

| 限制 | 说明 | 解决方案 |
|------|------|----------|
| 内存限制 | 微信小游戏 256MB | 使用对象池，避免长时间持有引用 |
| 文件大小 | 首包 4MB | 资源分包加载 |
| 性能 | 低端设备 | 降低分辨率，简化效果 |
