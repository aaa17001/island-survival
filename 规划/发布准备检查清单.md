## 发布流程

### Step 1: Unity构建
```
Unity Editor → IslandSurvival → 完整构建流程
输出目录: F:/FGame/Builds/WebGL/
```

### Step 2: 导出微信项目
```
1. 打开 F:/FGame/Builds/WebGL/
2. 复制 Build/ 目录
3. 复制 TemplateData/ 目录
4. 重命名为 game.js
```

### Step 3: 微信开发者工具
```
1. 新建小游戏项目
2. 导入导出的文件
3. 配置 game.json
4. 预览测试
```

### Step 4: 上传发布
```
1. 点击"上传"按钮
2. 填写版本信息
3. 提交审核
4. 等待审核通过
```
